Etapa 1: O Porteiro Inteligente (Context Manager)

Desafio: Marina abriu um arquivo no Python mas esqueceu de fechar, deixando a memória do computador presa. Qual código garante que o arquivo fecha sozinho?

# Opção A: Fechamento manual (arriscado) arq = open("dados.txt", "r") dados = arq.read() # Se acontecer um erro aqui, arq.close() NUNCA é executado! # Opção B: Context Manager oficial (Porteiro do Python) with open("dados.txt", "r", encoding="utf-8") as arq: dados = arq.read() # Ao sair do bloco, fecha e libera a memória sozinho!
❌ Opção A: open() manual
Abrir com open() e tentar lembrar de fechar depois na mão com arq.close().
✅ Opção B: with open() as arq:
Usar o comando with, que fecha o arquivo automaticamente mesmo com erros!

Etapa 3: Decisão de Negócio na Escrita ("w" vs. "a")

Desafio do Gerente: Já existem 50 vendas registradas de manhã no arquivo vendas.txt. Às 16h, você vai cadastrar uma nova venda. Qual modo de abertura você deve escolher?

# Decisão de Negócio: Registrar nova venda sem apagar as anteriores nova_venda = "Teclado Gamer, R$ 150.00 " with open("vendas.txt", "???", encoding="utf-8") as f: f.write(nova_venda)
🚜 Modo "w" (Write)
O 'trator': apaga todo o arquivo anterior e recria do zero.
📝 Modo "a" (Append)
O 'caderno': vai até o fim do arquivo e acrescenta a nova linha sem apagar nada!
